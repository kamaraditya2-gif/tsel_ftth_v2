Baik. Setup saat ini sudah siap digunakan:

File yang aktif:

docker-compose-infra.yml - PostgreSQL + Redis
docker-compose-app.yml - Worker + Dashboard

bash
# Start infrastructure
docker compose -f docker-compose-infra.yml up -d

Develepoment
Untuk development, ada 2 pendekatan:
----
Pendekatan 1: Development Mode (Recommended)

>>Dashboard (Next.js)
bash
cd dashboard
npm install
npm run dev
Dashboard akan berjalan di http://localhost:3000 dengan hot reload.

>>Worker
bash
cd worker
npm install
npm start
Worker akan berjalan secara terus-menerus.

>>Infrastructure (PostgreSQL + Redis)
Gunakan docker-compose untuk infrastructure:

bash
docker compose -f docker-compose-infra.yml up -d

Pendekatan 2: Docker dengan Development Config
Gunakan docker-compose tapi dengan development config:

bash
# Start infrastructure
docker compose -f docker-compose-infra.yml up -d
 
# Start dashboard dengan volume mount untuk hot reload
docker run -d --name mojojojo_dashboard \
  -p 3002:3000 \
  -v ./dashboard:/app \
  -v /app/node_modules \
  -v /app/.next \
  --network mojojojo_network \
  -e NEXT_PUBLIC_API_URL=http://localhost/api \
  -e INTERNAL_API_URL=http://localhost:3000 \
  -e DB_HOST=mojojojo_postgres \
  -e DB_PORT=5432 \
  -e DB_USER=mojojojo_user \
  -e DB_PASSWORD=mojojojo_password \
  -e DB_NAME=mojojojo_database \
  -e REDIS_HOST=mojojojo_redis \
  -e REDIS_PORT=6379 \
  mojo-dashboard:latest \
  npm run dev
Rekomendasi: Gunakan Pendekatan 1 untuk development karena lebih mudah dengan hot reload native dari Next.js dan Node.js.


------
Perbedaan npm run dev vs npm start
Dashboard (Next.js)
npm run dev (Development Mode)

Menjalankan next dev
Hot reload otomatis saat ada perubahan kode
Tidak perlu build sebelumnya
Lebih lambat karena compile on-the-fly
Port default: 3000
Untuk development
npm start (Production Mode)

Menjalankan next start
Perlu build dulu (npm run build)
Tidak ada hot reload
Lebih cepat karena sudah di-compile
Port default: 3000
Untuk production
Worker (Node.js)
npm start

Menjalankan node worker.js
Worker untuk memproses queue jobs dari Redis
npm run dispatcher

Menjalankan node dispatcher.js
Dispatcher untuk cek task scheduled dan buat queue jobs
Rekomendasi Development
bash
# Terminal 1 - Infrastructure
docker compose -f docker-compose-infra.yml up -d
 
# Terminal 2 - Dashboard (hot reload)
cd dashboard
npm run dev
 
# Terminal 3 - Worker
cd worker
npm start
 
# Terminal 4 - Dispatcher (opsional, jika ingin run terpisah)
cd worker
npm run dispatcher
Rekomendasi Production
bash
# Build dulu
cd dashboard
npm run build
 
# Jalankan di production
npm start

Cara development dengan hot reload:

bash
# Terminal 1 - Infrastructure
docker compose -f docker-compose-infra.yml up -d
 
# Terminal 2 - Dashboard
cd dashboard
npm run dev
 
# Terminal 3 - Worker (dengan hot reload)
cd worker
npm run dev
 
# Terminal 4 - Dispatcher (dengan hot reload)
cd worker
npm run dev:dispatcher
Perintah baru yang tersedia:

npm run dev - Worker dengan hot reload (nodemon)
npm run dev:dispatcher - Dispatcher dengan hot reload (nodemon)
npm start - Worker production (tanpa hot reload)
npm run dispatcher - Dispatcher production (tanpa hot reload)
Setiap kali Anda save perubahan di worker.js atau dispatcher.js, nodemon akan otomatis restart.
